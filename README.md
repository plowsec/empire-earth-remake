# Empire Earth: Atomic Conquest

A modern remake of *Empire Earth* (2001) focused on the **Atomic Modern** age on
**Big Islands** maps: one human against up to three AI opponents, with armies of
thousands of units fighting on land, at sea and in the air.

- **Engine:** Godot 4.7 (Forward+, Metal) for rendering, UI and audio.
- **Simulation:** a deterministic, fixed-point Rust core (`crates/ee_sim`). It's
  engine-independent and built for lockstep multiplayer.
- **Presentation:** compact side-panel HUD, muted terrain and foliage, aircraft crash
  trails and impact effects, listing/sinking ships, and a nuclear flash, shock front,
  rising smoke cloud and dedicated blast audio. Nuclear pressure propagates outward,
  pushes surviving ground/naval units, and topples trees as it reaches them.
- **Art:** every model is generated by Blender Python scripts (`tools/blender`).
  Textures and the sky are CC0 (Poly Haven). Sound effects are synthesized
  (`tools/audio`). Music is by Kevin MacLeod (CC BY 4.0).

## Quick start

```sh
./tools/build.sh                 # build the Rust GDExtension into game/bin
godot --path game                # play (main menu → Skirmish)
```

Requirements: Rust (stable), Godot 4.7, and Blender 5 (only to regenerate models).

## Controls

| Action | Input |
|---|---|
| Select / box-select | Left click / left drag (Shift adds, double-click = all of type) |
| Command (move, attack, gather, build, board, repair, rally) | Right click |
| Attack-move | `A` then left click |
| Building hotkeys (citizens) / training hotkeys (buildings) | `Q W E R T F G Z X C V B` (shown on buttons) |
| Stop / Unload transport / Return to airfield / Delete | `H` / `U` / `Y` / `Delete` |
| Control groups | `Ctrl+1..9` set, `1..9` recall (double tap to center) |
| Next idle citizen / all idle citizens | `;` or idle button / Shift-click idle button |
| Scout island | `S` |
| Mass training | Shift-click / Shift+training hotkey: 10 per selected building |
| Center on selection | `Space` |
| Camera | Arrows / screen edges to pan, wheel to zoom, middle-drag / two-finger scroll to pan, `,` `.` or Shift+middle-drag to rotate |
| Show all health bars | hold `Alt` |
| Pause menu (speed, save, restart) | `Esc` / `P` / `F10` |
| Quicksave | `F5` (load from the main menu → Load Game) |
| Debug overlay (fps, AI state) | `F1` |

Resources: mines are effectively bottomless, berry bushes and fish shoals regrow, and
farms never run dry. **Wood is the strategic resource.** Forests don't come back on their
own: citizens can **Plant Trees**, a 3×3 grove of saplings that costs food and grows into
full trees in two minutes. Artillery, bombs and naval shells flatten forests, so long
wars can strip an island bare.

Transports: select land units and right-click your landing ship to board, then
right-click a beach with the ship selected to land them. Aircraft fly from an
airfield, refuel and rearm there automatically, and crash when they run out of fuel. Right-click an area to patrol it; an airfield's
rally sends newly trained and refuelled aircraft there. Select a production building
to see its rally flag or use **Clear Rally**. Granaries can **Rebuild Fields** to lay
out available farm plots and assign a citizen to each. Saved control groups appear
above the minimap; click to recall, double-click to center.

Strategic weapons: a **Missile Silo** builds and stores up to three ICBMs; select it and
right-click any point (also on the minimap) to launch. Missiles fly a ballistic arc and
detonate as a full nuclear blast. Only **ABM Sites** can shoot them down, and only while
their owner has an **Early Warning Radar**, which also sounds the alarm on any enemy launch.
A **Fortress** garrisons up to 80 units; stored units don't count toward population.
**Apartment Blocks** house 50. Population limits go up to 3000.

Computer opponents use island scouting and granary field rebuilding. Hard and
Hardest opponents can invest in a nuclear bomber after their economy matures,
targeting visible enemy building clusters.

## Repository layout

```
crates/ee_sim       deterministic simulation (map gen, units, combat, economy, fog)
crates/ee_ai        computer opponent (economy, build planner, invasions, air/naval ops)
crates/ee_net       lockstep session + Transport trait (local today, network later)
crates/ee_godot     GDExtension: MultiMesh renderer, terrain, fog, picking, UI API
crates/ee_headless  CLI: map previews, AI-vs-AI soak tests, determinism checks
game/               Godot project (scenes, GDScript UI, shaders, assets)
tools/blender       procedural model pipeline (+ previews/icons)
tools/assets        texture fetch & packing, contact sheets
tools/audio         procedural sound effect synthesis
docs/ARCHITECTURE.md  design, multiplayer contract, scaling strategy
```

## Developer tools

```sh
cargo test --release -p ee_sim -p ee_ai -p ee_net     # simulation + AI tests
cargo run --release -p ee_headless -- match 1 2 60 2 # AI vs AI, 60 min, Hard
cargo run --release -p ee_headless -- match 1 2 60 3 3000 out.eerep # Hardest, 3000 pop, record
cargo run --release -p ee_headless -- map 7 2 out.ppm

blender -b -P tools/blender/build_models.py -- --icons   # rebuild all models + HUD icons
.venv/bin/python tools/audio/synth_sfx.py                # rebuild sound effects
python3 tools/assets/fetch_polyhaven.py && .venv/bin/python tools/assets/pack_terrain.py

tools/shot.sh out.png 200 --ai0 --warp=14000 --seed=5    # screenshot of a running match
godot --path game -- --scene=main --autotest             # end-to-end UI test
godot --path game -- --scene=main --savetest             # save/load round trip
godot --path game -- --scene=main --featuretest --seed=5 --reveal # feature inputs + screenshots in build/verification
godot --path game -- --scene=main --stress=1500 --reveal # 3000-unit battle benchmark
```

## Saves and replays

Saves (`user://saves/*.eesave`) are full snapshots: world plus AI state, so loading is
instant and the game continues bit-identically. Every match is also recorded as a replay
(`user://replays/*.eerep`, on macOS under `~/Library/Application Support/Godot/app_userdata/`):
match setup, AI seeds and every command, refreshed every 30 s and on exit.

```sh
ee_headless replay <file.eerep> [minutes_between_reports]
```

re-simulates a played game with freshly created AIs fed the human's recorded commands,
prints per-player economy/army/AI-state timelines, and verifies the recorded checksums
(any divergence is reported with its tick).

## Multiplayer readiness

The game is lockstep-ready but has no network transport yet:

- All game state lives in `ee_sim::World` and changes only through `World::step(commands)`.
- The state uses integer math, a seeded RNG and ordered iteration, so peers given the same
  inputs compute bit-identical states.
- Every player action, from the UI or the AI, is a serializable `Command`. The session
  schedules commands for `tick + input_delay`.
- Adding online play means implementing `ee_net::Transport` (exchange `TickCommands` and
  checksums). Replays already come free.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for details.
